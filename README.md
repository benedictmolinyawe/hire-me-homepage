# Benedict L. Molinyawe — Hire Me Personal Home Page

A responsive, static personal homepage designed with a black, dark-gray, and silver BLM calling-card theme.

## Sections
- Introduction and professional summary
- Skills and strengths
- Work experience, education, and credentials
- EcoSphere academic project
- Email, LinkedIn, and GitHub contact links

## Publish with GitHub Pages
1. Create a new public repository, for example `hire-me-homepage`.
2. Upload the contents of this folder (not the ZIP file). Make sure `index.html`, `style.css`, `script.js`, and `assets/` are in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.
